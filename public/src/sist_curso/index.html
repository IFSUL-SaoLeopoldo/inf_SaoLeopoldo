SOBRE O CURSO

Prepare-se para o Mercado de TI

Formação completa e prática para atuar em uma das áreas mais promissoras da atualidade

O curso Técnico Subsequente em Desenvolvimento de Sistemas do IFSul Campus São Leopoldo tem o objetivo de formar profissionais qualificados para o mercado de trabalho na área de desenvolvimento de software e sistemas computacionais.

O egresso do curso será capaz de atuar em diversos ramos de negócios, desempenhando atividades no desenvolvimento de sistemas desktop, web e mobile, modelagem de banco de dados e engenharia de software, além de gerenciar projetos de tecnologia da informação.

Com uma formação sólida e prática, você estará preparado para enfrentar os desafios do mercado de tecnologia e construir uma carreira de sucesso na área de TI.

Curso sem TCC: Mas conta com uma disciplina de Projeto de Sistemas em que o aluno será mentorado para desenvolver um projeto integrando os conhecimentos do curso.

Orientado a projetos: Você não só aprenderá teoria, mas também a aplicará em projetos reais, desenvolvendo habilidades essenciais por meio de projetos práticos.
